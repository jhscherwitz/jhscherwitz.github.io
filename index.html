Life Hub

TypeScript, React, Electron

A desktop app that runs my day: calendar, email, tasks and Canvas grades on one page, with an AI assistant that takes actions instead of only answering. Everything runs on my own computer, with no server and no account.

  • An AI agent built on Gemini function calling plans across 25+ tools, from moving calendar events to drafting emails, and every action it takes can be undone.
  • Google sign-in uses OAuth 2.0 with PKCE, and stored secrets are encrypted with the operating system's keychain.
  • The built-in browser runs in an isolated, sandboxed session with ad and tracker blocking.
  • Backed by 360+ unit tests in Vitest, with features checked end to end in Playwright.

LockedIn

JavaScript, Python

A study dashboard I use daily: a Pomodoro timer, ambient sounds, tasks, Google Calendar, Spotify and live study sessions with friends. No framework, no build step and no backend.

  • Google Calendar connects through OAuth 2.0 entirely in the browser, so no server ever holds a token.
  • Pause and resume sync across machines through a hand-written MQTT client of about 8KB, after WebRTC proved unreliable across home routers.
  • Discord Rich Presence talks to the Discord app over its local IPC protocol, using only Python's standard library.
